# 🛒 Amazon Web E-Commerce Landing Page Clone

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![Font Awesome](https://img.shields.io/badge/Font_Awesome-339AF0?style=for-the-badge&logo=fontawesome&logoColor=white)](https://fontawesome.com/)

A pixel-perfect visual clone of the Amazon E-Commerce homepage created with pure HTML5 and custom CSS3. Designed to replicate modern e-commerce user interface standards, navigation menus, product cards, and footers.

---

## ✨ Features & UI Components

- 🔍 **Amazon Navigation Bar**:
  - Logo branding
  - Delivery location indicator ("Deliver to India")
  - Multi-category search box with search icon dropdown
  - Sign-in account dropdown indicator
  - Returns & Orders tracker
  - Interactive shopping cart badge
- 📑 **Sub-Navigation Panel**:
  - Category menu ("Today's Deals", "Customer Service", "Best Sellers", "Gift Cards", "Sell")
  - Electronics deals banner link
- 🖼️ **Hero Section Banner**:
  - Welcome announcement banner with country localization link
- 🛍️ **Multi-Card Product Catalog Grid**:
  - Responsive multi-column product card layout
  - Categories: Health & Personal Care, Indoor Plants, Women's Clothing, Fresh Fruits & Vegetables, Headphones, Home Decoratives, and Fashion
- 👣 **Multi-Tier Amazon Footer**:
  - "Back to Top" smooth scroll trigger
  - 4-column corporate & help link lists (Get to Know Us, Connect with Us, Make Money with Us, Let Us Help You)
  - Logo section and copyright policy notice

---

## 🚀 How to View

1. Clone the repository:
   ```bash
   git clone https://github.com/B-LIPIKA/Clone.git
   cd Clone
   ```
2. Open `index.html` in your browser.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<section>`, `<footer>`)
- **CSS3**: Flexbox layouts, grid card positioning, custom media query breakpoints, hover states
- **Font Awesome 6.5**: Vector icons for search, cart, pin location, and mobile bar menu
